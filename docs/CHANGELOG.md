# Changelog

## v1.0.5

- Jade-style HUD overlay: opaque dark panel in the top-right corner
- Color swatch box next to hex code in HUD
- Port tag display (RJ / SFP / QSFP) in HUD
- Zero configuration required — works out of the box
- F2 color list window retained

## v1.0.0

- Initial release
- F2 overlay with scrollable hex color list
- Crosshair raycast targeting for cable spinners and racks
- Held cable detection via reflection
- Cable type classification (RJ / SFP / QSFP)
- Rack variant detection (Normal / Colored)
- Color aggregation from scene objects, save data, and JSON files
- Hex ↔ color conversion utilities
